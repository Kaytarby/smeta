# Оперплан (10 недель)

Локальная веб‑программа вместо AppSheet: общая смета на 10 недель, роли, Excel, лимиты.

Интернет **не нужен**. Одна база живёт на одном компьютере. Коллеги открывают её в браузере в той же сети.

## Как это устроено

Не кладите базу в общую папку. Несколько человек, пишущих в один файл, портят данные.

Правильная схема:

1. На **ноутбуке‑хосте** запускается `start.cmd` (или автозапуск).
2. В окне появляется адрес вида `http://192.168.1.23:3000`.
3. Коллеги в Chrome/Edge открывают этот адрес и входят своим логином.
4. Пока хост выключен или ушёл из сети — работать нельзя. Это ограничение ноутбука, не программы.

Нужен **Node.js 22+**. База: `data/operplan.sqlite` (после первого запуска переносится из старого `data/store.json`). Копии: `data/backups/` (до 14 штук, плюс кнопка «Бэкап сейчас»).

## Запуск на ноутбуке

```bat
start.cmd
```

или:

```bat
npm start
```

Слушает `0.0.0.0:3000` — доступен из LAN, не только с этого ПК.

Автозапуск после входа в Windows:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\install-autostart.ps1
```

Снять: `scripts\uninstall-autostart.ps1`.

Если коллеги не открывают адрес: один Wi‑Fi/офисная сеть; на хосте в брандмауэре разрешить TCP 3000 (скрипт автозапуска умеет спросить).

## Учётка

Пользователей создаёт администратор в разделе «Администрирование». Пароли в интерфейсе входа больше не показываются.

## Что важно знать

- Хост = этот ноутбук. Выключили — база недоступна всем.
- Бэкапы можно копировать на сетевой диск; **живой** sqlite туда не класть.
- Ночной сдвиг недель работает, только пока запущен процесс (окно `start.cmd` или задача автозапуска).
